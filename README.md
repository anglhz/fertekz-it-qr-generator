
# Fertekz IT - QR Generator

A modern and customizable QR code generator built with Next.js, React, TypeScript and Tailwind CSS.

## Features

- Generate QR codes from URLs
- Customize foreground and background colors
- Choose between six different QR code styles
- Upload a custom logo
- Adjust logo size
- Real-time design preview
- High-resolution PNG export
- SVG export
- Responsive interface
- Client-side processing

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- QR Code Styling

## Getting Started

Clone the repository and install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.

## Privacy

All QR codes and uploaded logos are processed locally in the browser.

No database or backend is required.
